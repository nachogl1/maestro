    Throwaway prototype — Work Journal cards

    • Click the project chip to pick another open project, or none.
    • The source tag is fixed; a hand-made card says Typed.

    • + Add entry (right of the formatting buttons) adds an empty card at the end with the current time.
    • Accept in Suggestions also adds a card at the end.
