PROJECTS pill (throwaway prototype)

Built only to react to; it is thrown away once you have. All data is made up. Click PROJECTS in the bar above.

  • Level 1: your open project tabs. A project with no GitHub repository is greyed out.
  • Level 2: every label of that repository with its open-issue count; a label with no open issue shows 0.
  • Level 3: that label's open issues by number and title; clicking one opens it on GitHub.
  • Lock button: on (default) counts blocked issues too, and marks them with a small lock; off counts and lists only ready issues. Hover it for the message. It is remembered across restarts.
  • Loading: a spinner each time the list is opened; nothing polls in the background. Try project docs-site to see a failed load.

Approved by the maintainer on 2026-11-08: step in one level at a time, with a back arrow and a clickable path at the top.
