Throwaway prototype — Files tab

Not real code. It only shows how the decided pieces look together. Names and paths are made up.

  • Click a terminal on the right: the box above the tree switches to that terminal's folder. Green WORKTREE or grey PROJECT says which kind it is.
  • Click a folder to open it one level. node_modules shows a short "Loading…" (each folder loads only when opened).
  • Click a file to preview it below the tree (read-only). Double-click opens it in the computer's default app.
  • Hover a file for two quick buttons: copy its full path, open in default app. Right-click gives the same as a menu.
  • Click logo.png or dist/app.js (2.4 MB) to see the "Can't preview" state.
  • Hidden files (.env, .claude) show like any file. Git-ignored ones (node_modules, dist) are only dimmed, never hidden.
  • Files is the fourth tab, after Settings, so the Alt+1 to Alt+3 shortcuts keep their tabs and Files gets Alt+4.
